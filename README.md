# Fama-French Factor Replication

Building SMB, HML, RMW, CMA and UMD — and the Hou-Xue-Zhang q-factors — from individual CRSP and
Compustat records, and accounting for every measurable part of the difference from the published
series.

> **Status: done criterion met.** Bottom-up HML correlates **0.9960** with Kenneth French's
> published HML over 1990–2020 (spec: > 0.99). 464 tests, 96% coverage, offline suite in CI; the
> criterion itself is an integration test. Reasoning, dead ends and corrections are logged in [`LOG.md`](LOG.md); a
> plain-language walkthrough is in [`EXPLANATION.md`](EXPLANATION.md).

## Result

Monthly factor returns built here against French's published series, 1990-01 – 2020-12 (372
months). The reference is his **December 2024 release** — the last one built from the same legacy
CRSP files (SIZ) this build reads. Against his current release, rebuilt from CRSP's new CIZ format
in 2025, every number is within 0.001.

The derived factor series are versioned in [`data/results/bottom_up/factors.csv`](data/results/bottom_up/factors.csv)
and [`data/results/qfactors/q_factors.csv`](data/results/qfactors/q_factors.csv) (decimal monthly

For scale: **French's own two releases agree with each other at 0.9991** for HML over the same
window, with single months differing by up to 81 bp. That is what a change of data vintage alone
does to a factor built by its author from the same firms, so it is the floor against which the
0.9960 should be read — not 1.0.

**Caveats that belong next to the number.** This replicates a published *academic* series,
including its conventions and its use of restated accounting data; nothing here is a tradeable
backtest (see [Limitations](#limitations)). R² clears 0.99 for Mkt-RF, SMB, HML and UMD but not for
RMW (0.987) or CMA (0.985), and tracking error is 11–30 bp/month, not the "few basis points" the
spec's goal sentence hopes for. The fit is weaker before 1990 — HML 0.989 in the 1960s against
0.999 in the 2010s, RMW and CMA 0.983 and 0.988 over 1963–1989 — where fewer companies reach
Compustat.

### Where the remaining gap comes from

Each row rebuilds HML with exactly one choice changed (`scripts/attribution.py`):

| Change from the shipped build | HML corr, 1990–2020 | HML corr, 1963–2024 |
|---|---|---|
| *French's CIZ release vs his SIZ release (the vintage floor)* | *0.9991* | *0.9993* |
| **Shipped build** | **0.9960** | **0.9962** |
| Deferred taxes added in every year, as the definition reads | 0.9744 | 0.9831 |
| Link on Compustat's header CUSIP only | 0.9922 | 0.9924 |
| No issuer-level (6-character) CUSIP links | 0.9954 | 0.9947 |
| No Moody's book equity (Compustat only) | 0.9960 | 0.9927 |
| Size breakpoint from each sort's own NYSE sample | 0.9954 | 0.9958 |
| Fama-French (1993) two-year Compustat requirement | 0.9960 | 0.9956 |
| French's published breakpoints instead of derived ones | 0.9963 | 0.9964 |
| No delisting returns at all | 0.9960 | 0.9963 |

- **The accounting conventions matter most.** French stopped adding deferred taxes for fiscal years
  from 1993 (his August 2016 change note, citing FASB 109); applying the literal definition costs
  0.022 of correlation. Moody's hand-collected book equity, which French also uses, carries the
  1960s and 1970s.
- **Linkage is the largest remaining component.** CRSP/Compustat Merged is not in this
  subscription, so companies are linked through shared CUSIPs. Reaching Compustat's full security
  table and matching on the 6-character issuer code are together worth +0.004; what no CUSIP path
  reaches shows up as the small portfolios holding 96–98% of French's firm counts, against
  99–100% for the big ones.
- **Derived breakpoints are nearly free**: substituting French's own buys +0.0003.
- **Delisting treatment is invisible at the factor level** (< 0.5 bp/month) — a correctness fix
  in the portfolio arithmetic, not a source of the gap.
- **Neither rejected alternative is what French does now.** The two-year Compustat rule and a
  per-sort size breakpoint both fit worse, which is evidence for the defaults, fixed from his
  current wording before any result existed.

### q-factors and spanning tests

The Hou-Xue-Zhang (2015) q-factors — a monthly 2 × 3 × 3 sort on size, investment-to-assets and
quarterly ROE from the latest *announced* earnings — correlate with global-q.org's published series
at **ME 0.994, ROE 0.987, I/A 0.972** over 1990–2020, and 0.993 / 0.982 / 0.973 over their full
1967–2024 sample. Quarterly book equity is imputed as HXZ do, which is what reaches 1967: firm
counts before 1972 track theirs within about 5% (January 1971: 1,512 against 1,446).
Spanning tests, 1967–2024, identical 696 months for both sets of series:

| | Published series | Built here |
|---|---|---|
| ROE alpha against FF5, %/month (t) | 0.40 (5.7) | 0.46 (6.6) |
| ROE alpha against FF5 + UMD | 0.24 (4.2) | 0.30 (5.1) |
| GRS: q-factors on FF5 (p) | 11.2 (0.000) | 14.5 (0.000) |
| GRS: SMB, HML, RMW, CMA, UMD on the q-model (p) | 0.99 (0.43) | 1.42 (0.22) |

Both reproduce the literature: FF5 does not price ROE, and the q-model prices every Fama-French
factor, momentum included. One disagreement is reported rather than smoothed: the investment
factor's alpha against FF5 + UMD has t = 2.09 here and 1.86 in the published series.

## Method

The protocol is French's, followed from his own descriptions and change notes; every choice the
text leaves open is an explicit, ablatable switch (`construct/formation.py: Conventions`).

1. **Universe.** CRSP monthly (SIZ), NYSE/AMEX/NASDAQ ordinary common shares (share codes 10/11),
   with names and codes joined point-in-time. Blank-check companies (SIC 6799) are excluded — a
   screen measured on all 866 months of French's NYSE breakpoints (median error 0.08% against
   0.17% without it) and consistent with his September 2021 note on excluding investment funds
   "through time". Market equity is aggregated to the company across share classes.
2. **Delisting returns** are matched to the calendar month, with Shumway's −30% for performance
   delistings missing a return; a delisting after a security's last monthly row becomes its own
   final month (25,761 of 38,843 events), so the loss reaches the portfolio.
3. **Accounting.** Book equity is SE + DT − PS with the Davis-Fama-French fallback hierarchies,
   deferred taxes through fiscal 1992, and French's Moody's book equity where Compustat has none.
   Operating profitability is (revenue − COGS − SG&A − interest) / (BE + minority interest).
   Investment is asset growth between *consecutive* fiscal years.
4. **Linking.** Each CRSP company reaches Compustat through every CUSIP any of its share classes
   carried, against both the header CUSIP and every issue in `comp.security`, and — as the weakest
   path, used only where no full CUSIP connects — through the 6-character issuer code, which
   identifies the company rather than the share class. Ambiguities are resolved deterministically
   (strongest path first) and counted per year.
5. **Formation.** Each June: size from June market equity, BE/ME from December market equity,
   accounting from the fiscal year ending the previous calendar year; NYSE breakpoints (median;
   30th/70th percentiles, `lower` interpolation, selected against French's files) applied to every
   listed firm; each sort restricted to the sample French states for it. Portfolios are value
   weighted and held July–June with weights drifting on price return only.
6. **Momentum and the market** are rebalanced monthly: size × prior (t−12 … t−2) return with
   French's inclusion rule, and the value-weighted market.
7. **q-factors** follow the global-q.org technical document (July 2026): financials and negative
   book equity excluded; ROE re-sorted monthly on the most recent quarter announced after its
   quarter end and ended within six months (before 1972, the quarter ended at least four months
   earlier); missing quarterly book equity filled from the annual file and by clean surplus,
   backward then forward up to four quarters, with dividends from `DVPSXQ` and split-adjusted
   shares.

Validated against external references at every layer: the universe against French's NYSE size
breakpoints; book equity, profitability and investment against his BE/ME (0.69% mean absolute
error), OP (0.37pp) and INV (0.79pp) breakpoints over 1975–2024; portfolio returns and firm counts
against his six-portfolio files; q-portfolios against global-q's 18 benchmark portfolios.

## Limitations

These bound what any number here can mean.

- **Restated data, so not tradeable.** Compustat Point-in-Time is not in this subscription;
  `comp.funda` carries restatements made after the fact. French uses restated data too, which helps
  the replication and rules out any claim that these factors could have been traded as computed.
- **No CRSP/Compustat Merged link.** Through the CUSIP-based link, 95–98% of June companies by
  count and 96–99% by market equity reach a Compustat record for the prior fiscal year from 2000 on
  (decade averages), and fewer before — 68–80% by count in the 1960s–80s. That share also counts
  new listings with no prior-year accounting yet, so it understates the link itself; what is missed
  skews small either way. A failed match is not evidence the firm is absent from Compustat — only
  that no CUSIP path connects them. Issuer-code matching raises the number of companies with more
  than one candidate GVKEY (3,214 company-years over 1963–2024, against 556 without it); each is
  resolved to the strongest CUSIP path, and every fit statistic improved with it, but a CUSIP-based
  link remains a reconstruction of CCM, not CCM.
- **CRSP's legacy monthly file ends December 2024.** Every comparison stops there. French's current
  files are built from a newer CRSP vintage and a different return definition (CIZ); the December
  2024 release is used as the primary reference for that reason.
- **Before 1990 the fit is weaker**, most for RMW and CMA (0.983, 0.988 over 1963–1989), which
  Moody's book equity cannot help. Their big-stock portfolios held 79–90% of French's firm counts
  before issuer-level linking and still run short; early Compustat coverage is the measured cause.
- **I/A tracks global-q at 0.97 with a slope near 0.92** — ours is 5% more volatile. Four candidate
  causes were tested and ruled out (the size breakpoint's sample, an annual versus a current-quarter
  negative-book-equity screen, excluding bid/ask-priced months); none moved the slope. The excess
  is concentrated in small high-investment portfolios, which hold 10–23% more firms than HXZ's.
  Unexplained.
- **The momentum inclusion rule is approximated.** CRSP's missing-return codes (−66, −77, −88, −99)
  arrive from WRDS as NULLs; a missing return is tolerated when the security has a row with no price
  that month (the −99 case) and disqualifies it otherwise.
- **Two conventions were confirmed by fitting French's published numbers, not only by his text**:
  the SIC 6799 screen and the `lower` breakpoint interpolation. Both were scored against
  alternatives over decades of his data, and the SIC screen has a documented rationale; neither is a
  rule he states in those words.

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.lock -r requirements-wrds.lock   # the second only for WRDS access
pip install -e . --no-deps

python scripts/fetch_reference_data.py              # French (two releases), Moody's BE, global-q
pytest                                              # 430 pass on a fresh clone; data tests skip

# with a WRDS subscription (credentials in ~/.pgpass, mode 0600)
export WRDS_USERNAME=<user>
python scripts/extract_wrds.py < /dev/null          # ~4 min; approve one Duo push
python scripts/build_factors.py                     # ~1 min; all FF factors vs French
python scripts/attribution.py                       # ~3 min; the gap table above
python scripts/validate_characteristics.py          # BE/ME, OP, INV vs French's breakpoints
python scripts/build_qfactors.py                    # q-factors vs global-q, spanning tests
pytest tests/integration/test_bottom_up.py          # the done criterion, ~40 s
```

WRDS is reached through a plain SQLAlchemy/psycopg2 connection with the password read from
`~/.pgpass`, not through the `wrds` package, whose every release pins `pandas<2.3`. A login may wait
up to two minutes on a Duo push to the account holder; the extract checks every requested column
against `information_schema` before pulling. Extracts go to the gitignored `data/processed/`.

Requires Python 3.12+ (numpy 2.5 and scipy 1.18 do). Verified on Python 3.13.9 with pandas 3.0.5,
numpy 2.5.2, scipy 1.18.0, including a clean install from the lock; CI runs the offline suite
on 3.12 and 3.13 (`.github/workflows/tests.yml`).

## Layout

```
src/ffrep/
  reference/   French's and global-q's published files: download, parse, relabel
  universe/    CRSP extraction, share screen, delisting, monthly panel, CUSIP links
  construct/   book equity, sorts, formation join, portfolios, factor algebra, momentum
  qfactor/     quarterly ROE and the 2 x 3 x 3 sort
  evaluate/    fit statistics, Newey-West OLS, GRS, spanning tests, the step-1 proxy
  pipeline.py  wiring only: extracts in, factors out
  store.py     atomic Parquet writes, checksums, numpy dtypes at the boundary
scripts/       one per step; each prints and writes its tables
```

## Data sources

- **CRSP monthly stock file (SIZ) and Compustat annual, quarterly and security tables**, via WRDS.
  Licensed; never committed.
- **Ken French's data library** (free): published factors, six-portfolio files with firm counts,
  NYSE breakpoints — current release and the December 2024 archive — and the Davis-Fama-French
  Moody's book equity.
- **global-q.org** (free): Hou-Xue-Zhang q5 factors and 18 benchmark portfolios.

## Earlier results in this project

Before WRDS access, the project measured how far a large-cap-only universe could go using French's
own portfolios: his big-stock value spread correlates **0.92** with HML over 1926–2026 (0.88 over
1990–2020), because small- and large-cap value spreads co-move at only ρ ≈ 0.6. That settled that
free data could not meet the criterion. It is one construction's measured correlation, not a bound
on all of them; earlier wording in this repository called it a ceiling no implementation could
beat, which overstated it.

**Project 02** (event-driven backtester) reproduced HML to 0.5 bp from French's *portfolios*,
validating its accounting. This project builds the portfolios themselves from firm data.
